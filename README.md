# DataPilot

Drop in a CSV, and an agent profiles it, charts it, and answers your questions in plain English, with you in control of every step.

Built with [Agent-Native](https://www.agent-native.com) for the Agent-Native Hackathon (Nov 2026).

## What it does

1. **Load a file.** Drag in a CSV (up to about 6 MB / 50,000 rows) or pick a built-in sample: online shop sales, Iris flowers, or a deliberately messy file.
2. **See what's in it.** Row and column counts, each column's type, empty cells, distinct values, and a summary of what it holds.
3. **Chart it.** Histograms, top-value bars and two-column scatter plots with correlation. Re-point any chart at another column from the page.
4. **Ask questions.** "Which category sells the most units?" gets an answer plus a table of the exact numbers behind it.
5. **Pin findings** with their source numbers, and get a plain-English summary of the whole file.

## Why the numbers can be trusted

- All statistics are computed in code (`shared/stats.ts`). The model never does the arithmetic.
- The model can only call exact tools: totals, averages, counts, correlations (`server/lib/llm.ts`).
- Every number in a reply is checked against the computed profile and tool results (`shared/verify.ts`). Anything that fails the check is flagged to the user instead of shown as fact.
- The model never receives the whole file: only column statistics, five sample rows, and tool results.

## How the agent and the UI share one app

Each capability is one `defineAction` in `actions/`. The same action is an agent tool, a typed hook for the React UI, and an HTTP endpoint. A chart the agent adds is the chart you can edit; an answer the agent writes is the answer you can pin.

| Action | Purpose |
|---|---|
| `profile_dataset` | Parse and profile a CSV |
| `plot_column` | Histogram or top-value bar for one column |
| `compare_columns` | Scatter plot and correlation for two number columns |
| `sum_by` | Exact totals per category |
| `summarize_findings` | Plain-English summary written from computed numbers |
| `answer_question` | Sourced answer to a question |
| `get_dashboard` | Current screen state (dataset, charts, pins, answers) |
| `pin_finding`, `remove_chart` | Keep or remove items |

The UI is a single page at `/datapilot` (`app/routes/datapilot.tsx`).

## Run it locally

You need Node.js 22.22 or later and pnpm.

```bash
pnpm install
```

Create a `.env` file (it is gitignored) with a Google Gemini API key:

```bash
GOOGLE_GENERATIVE_AI_API_KEY=your-key-here
```

```bash
pnpm dev
```

Open http://localhost:8080 and choose "Continue as local dev" on the welcome screen. Restart `pnpm dev` after changing `.env`.

On Windows, keep the project path free of spaces; `pnpm` scripts fail on paths like `D:\My Projects\...`.

### Models

By default the app tries `gemini-3.8-flash`, then `gemini-3.5-flash`, then `gemini-3.1-flash-lite`, moving on automatically when a model is busy or unavailable. Override the order with a comma-separated list:

```bash
DATAPILOT_MODELS=gemini-3.8-flash,gemini-3.5-flash
```

### Tests

```bash
pnpm vitest --run tests
```

The tests cover CSV edge cases (quoted commas, multi-line fields, mixed types, blanks), the statistics, and the number checker.

## Project layout

- `actions/`: the Agent-Native actions listed above
- `shared/stats.ts`, `shared/verify.ts`: pure TypeScript statistics and the number checker
- `server/lib/`: dataset state and the model layer
- `app/routes/datapilot.tsx`, `app/components/datapilot/`: the UI
- `public/samples/`: the three sample CSVs (the retail data is synthetic, generated by `scripts/gen-retail.ts`)
- `DEPLOY.md`: deployment notes (needs a Postgres database; see the Windows notes there)

## What came from where

- **Starter:** the Agent-Native "chat" template (MIT). Its scaffold, settings and agent chat are unchanged; only the sidebar’s first link and the root redirect were edited to open DataPilot.
- **Written for this hackathon:** everything listed under "Project layout", plus the root redirect and sidebar entry that open DataPilot.
- **Earlier concept:** the idea builds on the author's earlier ChatEDA (Flip the Switch, Nov 4). This is a new implementation in Agent-Native; no code was reused.
- **Libraries:** PapaParse, Recharts, the Vercel AI SDK with Google Gemini, and the Schibsted Grotesk font. Iris data comes from scikit-learn's bundled copy of the classic dataset.
