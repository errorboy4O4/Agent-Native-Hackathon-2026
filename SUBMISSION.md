# DataPilot: submission pack

## Project description (paste into the form)

DataPilot is an agentic data-analysis app built with Agent-Native. Drop in a CSV and the agent profiles it, charts it, and answers follow-up questions in plain English. The agent and the interface share the same actions, so what the agent computes is exactly what you see and control: a chart the agent adds is the chart you can re-point at another column, and an answer you pin stays on screen with the numbers behind it.

All statistics are computed deterministically in code. The model never calculates: it can only call exact tools (totals, averages, counts, correlations), and every number in its reply is checked against the computed profile and tool results. Anything that fails the check is flagged to the user instead of presented as fact. Only column statistics, five sample rows and tool results go to the model, never the full file.

**Pre-existing work, disclosed:** the concept builds on the founder's earlier ChatEDA (Flip the Switch, Nov 4). This app is a new implementation in Agent-Native, written Nov 5 onward for this hackathon, in a new repository. No ChatEDA code was reused.

**Third-party pieces:** Agent-Native chat template (scaffold, MIT), PapaParse (CSV parsing), Recharts (charts), Vercel AI SDK with Google Gemini (language model), Schibsted Grotesk font. The Iris sample data comes from scikit-learn's bundled copy of the classic dataset; the retail sample is synthetic and generated by `scripts/gen-retail.ts`.

**What changed during the event:** everything under `actions/`, `shared/`, `server/lib/`, `app/routes/datapilot.tsx`, `app/components/datapilot/`, `tests/`, `scripts/` and `public/samples/`, plus the root redirect and sidebar entry. The template's own chat/sidebar/settings code is unchanged.
